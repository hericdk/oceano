# Oceano

ဂိမ်းဆော့သူ၊ ဖန်တီးသူနဲ့ ပရိုဂရမ်ရေးသူတွေအတွက် ရိုးရှင်းပြီး ပွင့်လင်းတဲ့ ပစ်ဇယ်အနုပညာ ဘရောက်ဇာ။
Chromium အပေါ် အခြေခံထားပြီး သင်ခွင့်ပြုမှသာ အမည်မသိ အသုံးပြုမှု ရေတွက်ပါတယ်။ ဇာတ်ညွှန်းအမျိုးအစား theme တွေနဲ့ Lua (PUC-Rio မှာ ဖန်တီးခဲ့တဲ့ ဘာသာစကား) mod တွေ ပါဝင်ပါတယ်။
ပစ်ဇယ်ပင်လယ်ပေါ်က ဝင်းဒိုးစားပွဲလို ပင်မစာမျက်နှာ၊ ပြီးတော့ ဘရောက်ဇာထဲမှာတင်
ဖန်တီးရေးကိရိယာတွေလည်း ပါပါတယ်။

> **အခြေအနေ:** ဖွံ့ဖြိုးဆဲ။ → macOS (Apple Silicon) · Windows · Linux: [Releases](https://github.com/hericdk/oceano/releases/latest)

## ဘာကြောင့် ရှိနေတာလဲ

> Oceano က ဘရောက်ဇာတစ်ခု ထပ်တိုးရုံနဲ့ မကျေနပ်ပါဘူး။ လူတွေ ဖန်တီးတဲ့၊ သင်ယူတဲ့၊ သူတို့ အိပ်မက်တွေကို ပြသနိုင်တဲ့ နေရာဖြစ်ချင်ပါတယ်။

Oceano ကို ပစ်ဇယ်တွေနဲ့ လုပ်ထားတာပါ၊ တကယ့်ပင်လယ် မဟုတ်ပေမယ့် ပင်လယ်ကို ကြည့်ရတဲ့ ခံစားချက်အတိုင်း ပေးချင်ပါတယ်။
ကျယ်ဝန်းမှု၊ လွတ်လပ်မှု၊ ဖြစ်နိုင်ခြေတွေ ပြည့်နေတဲ့ ကောင်းကင်စပ်။ ကျွန်မ ဘယ်ကို သွားနိုင်မလဲ။ ဘယ်အထိ ကြီးထွားနိုင်မလဲ။
ဘယ်ကို ရောက်နိုင်မလဲ။ ဒီမေးခွန်းတွေကို လူတွေ ဖြေနိုင်အောင် ကူညီဖို့ ရှိနေတာဖြစ်ပြီး ဒါကြောင့်လည်း အခမဲ့ပါ။

ဖန်တီးသူတွေနဲ့ ဗီဒီယိုရိုက်သူတွေအတွက် ဖန်တီးထားတာပါ၊ အထူးသဖြင့် စတင်နေသူတွေအတွက်။ ကိုယ်ပိုင်
စီးပွားရေး၊ အကြံဉာဏ်တစ်ခု၊ အိပ်မက်တစ်ခုကို မိတ်ဆက်ဖို့၊ vlog ရိုက်ဖို့။ ကိရိယာတိုင်းက တစ်ခုခု သင်ပေးရမယ်၊ ပြီးတော့ အသိုင်းအဝိုင်းက
(အသိပညာ ဖလှယ်တဲ့ အုပ်စုတွေ၊ ဖိုရမ်ရဲ့ အရှိန်အတိုင်း) လူတိုင်း ကြီးထွားလာအောင် ကူညီရမယ်။ ဒါက စီမံကိန်းတစ်ခုလုံးကို
ပြောင်းပြန်ဦးတည်စေတဲ့ အခြေခံအယူအဆပါ။ [manifesto](../MANIFESTO.md) ကို ဖတ်ကြည့်ပါ။

ဘရောက်ဇာတွေက တစ်ခုနဲ့တစ်ခု ဆင်တူလာပြီး ဘယ်သူမှ မတောင်းထားတာတွေနဲ့ ပြည့်နေပါပြီ။ Oceano က
ဆန့်ကျင်ဘက်ကို လိုချင်တယ်။ သေးငယ်ပြီး လှပပြီး စစ်ဆေးနိုင်ပြီး ကိုင်တွယ်ဖို့ ဖန်တီးထားတာ။ မစုဆောင်းတာက ကာကွယ်တာထက် ပိုကောင်းတယ်၊
အားလုံးက သင့်ကွန်ပျူတာထဲမှာပဲ ရှိတယ်၊ အကောင့်မလိုဘူး။

ဒါက အလယ်အလတ်နဲ့ ရေရှည်စီမံကိန်းပါ။ ကျွန်မအနေနဲ့ နှစ်ပေါင်းများစွာ အချိန်ပေးဖို့ စိတ်ကူးထားပါတယ်၊
Sean Murray က No Man's Sky ကို အချိန်ပေးခဲ့သလိုမျိုး။ စောစောထုတ်ပြီး အသုံးပြုသူတွေကို နားထောင်ပြီး ဗားရှင်းပြီးတစ်ခု
ဗားရှင်းတစ်ခု ဆက်တိုးတက်အောင်လုပ်ပြီး သူကတိပေးထားတဲ့ ဘရောက်ဇာဖြစ်သည်အထိ။ ပြီးတော့ ပွင့်ပွင့်လင်းလင်း လုပ်မယ်၊ တခြား
လူတွေ လေ့လာနိုင်၊ စိတ်ကူးရနိုင်ပြီး အကြံဉာဏ်တွေကို ဆက်သယ်သွားနိုင်အောင်။

အပြည့်အစုံ အမြင်ကို [`docs/VISAO.md`](../VISAO.md) မှာ ဖတ်နိုင်ပါတယ်။

### မေးခွန်းလေးခု၊ ဖန်တီးသူကိုယ်တိုင် ဖြေထားတာ

**အသုံးပြုသူကို တစ်ခုခု သင်ပေးလား။**

ဂီတသင်ယူရတာ ခက်တယ်လို့ ကျွန်မ ထင်ခဲ့တာပါ။ synthesizer တစ်လုံးနဲ့ မခက်ဘူးဆိုတာ သိလာခဲ့တယ်။ တခြားလူတွေလည်း သင်ယူနိုင်အောင် တန်းတူ ဝင်ရောက်ခွင့် ပေးချင်ပါတယ်။

**စတင်သူတွေအတွက် အလုပ်ဖြစ်ပြီး ဗီဒီယိုထဲမှာ ကြည့်ကောင်းလား။**

ဟုတ်ကဲ့! ဒီမှာ ဘာတွေလုပ်နိုင်လဲဆိုတာ ပြတဲ့ ဗီဒီယိုတွေ လူများများ လုပ်လေ၊ ထူးခြားပြီး လွတ်လပ်တဲ့ တစ်ခုခုကို စဖန်တီးမယ့်သူ များလေပါပဲ။

**ကိုယ်ရေးကိုယ်တာလုံခြုံမှုနဲ့ အသုံးပြုရလွယ်ကူမှုကို လေးစားလား။**

အစကတည်းက အခြေခံမူတစ်ခုပါ။ နှစ်ခုလုံး အရေးကြီးပြီး လိုအပ်တယ်၊ ဒီ beta ရဲ့ ပထမဆုံး စမ်းသပ်မှုတွေမှာ လူတိုင်းရဲ့ ထောက်ခံမှုကို ကျွန်မ မျှော်လင့်ပါတယ်။

**လူတွေကို တစ်ယောက်နဲ့တစ်ယောက် ပိုနီးစပ်စေလား။**

နောက်ပိုင်းမှာ ဖြစ်ချင်ဖြစ်မှာပေါ့။ Reddit စတိုင် ဆွေးနွေးဖိုရမ်တစ်ခုက အရမ်းကောင်းမယ်။ ပြီးတော့ အလေးချိန်အလွန်ပေါ့တဲ့ 3D ပတ်ဝန်းကျင်ဖန်တီးတဲ့ ဂရပ်ဖစ်ကိရိယာ ကျွန်မတို့မှာ ရှိပြီးသား။ ကောင်းကင်၊ မီးပြတိုက်၊ မိုးပါတဲ့ ပင်လယ်မြင်ကွင်းတစ်ခုလုံး ကုဒ် 29 KB ထဲ ဆန့်ပါတယ်။ ဒါက လူတွေကို ပိုနီးစပ်စေနိုင်တဲ့ အလားအလာ ကြီးကြီးမားမား ဖွင့်ပေးတယ် 👀

> အသစ်၊ လုံခြုံ၊ အချိတ်အဆက်ရှိ၊ လွတ်လပ်ပြီး အသုံးပြုသူတွေကို ကူညီဖို့ စဉ်းစားထားတဲ့ တစ်ခုကို ဖန်တီးဖို့ အံ့ဩစရာ အလားအလာ ကျွန်မတို့မှာ ရှိပါတယ်၊ ကျေးဇူးတင်မှု၊ စာနာမှုနဲ့ ဖလှယ်မှုရဲ့ သင်္ကေတအဖြစ်။ ပြီးတော့ ဒါအားလုံးကို ကြော်ငြာကင်းစင်အောင် ထိန်းထားဖို့ ရည်ရွယ်ပါတယ်။

## ရှိပြီးသားတွေ

| ဖိုလ်ဒါ | ဘာလဲ | ဘယ်လို run မလဲ |
|---|---|---|
| [`simulador/`](../../simulador/) | စာမျက်နှာတစ်ခုပေါ်မှာ run နေတဲ့ interface တစ်ခုလုံး၊ tab တွေ၊ စားပွဲ၊ theme တွေ၊ Lua/Teal mod တွေ၊ နောက်ခံတေးသံ၊ Strudel၊ PICO-8၊ ရေသောက်ရန် သတိပေးချက် | `python3 simulador/serve.py 5216` ပြီး http://localhost:5216 ကို ဖွင့်ပါ |
| [`app/`](../../app/) | Electron MVP၊ တကယ့် tab (Chromium)၊ သီးခြားခွဲထားတဲ့ ပရိုဖိုင်၊ blocker၊ mini player ပါတဲ့ အတူတူ interface | `cd app && npm install && npm start` |
| [`extensao/`](../../extensao/) | Oceano Lite၊ Chrome extension အဖြစ် Oceano ရဲ့ tab အသစ် | `extensao/README.md` ကို ကြည့်ပါ |
| [`docs/`](../) | အမြင်နဲ့ အစီအစဉ် | — |

ဒီနေ့ လုပ်နိုင်တာ အနည်းငယ်:

- **စားပွဲအဖြစ် ပင်မစာမျက်နှာ:** မီးပြတိုက်ပါတဲ့ ပင်လယ်ပေါ်မှာ ဆွဲရွှေ့၊ ခေါက်သိမ်း၊ ပိတ်လို့ရတဲ့ ဝင်းဒိုးတွေ၊ ပရိုဖိုင်တိုင်းမှာ ကိုယ်ပိုင်စားပွဲရှိတယ်။
- **Theme တွေ** (`oceano-tema/1`၊ JSON သီးသန့်) အရောင်တွေ၊ ပစ်ဇယ်ဆန်မှုနဲ့ ပင်လယ်ရဲ့ နေ့အချိန်ကိုတောင် ပြောင်းပေးတယ်။
- **Lua 5.4 / Teal mod တွေ** ကြေညာထားတဲ့ ခွင့်ပြုချက်တွေပါတဲ့ sandbox ထဲမှာ။
- **Tab အုပ်စုတွေ** ပင်မစာမျက်နှာမှာ သိမ်းထားပြီး မမ်မိုရီမစားအောင် ပိတ်ထားတယ်။
- **AI ရှာဖွေမှု** (ရွေးချယ်ခွင့်၊ သင့်ကိုယ်ပိုင် key နဲ့) တစ်ကြောင်းတည်း ဖြေပြီး မှန်တဲ့ဝဘ်ဆိုက်တွေကို ညွှန်ပြတယ်။
- **ဂီတ:** [Stave](https://stave.live) မှတစ်ဆင့် generative နောက်ခံတေးသံနဲ့ Strudel live coding (timeline၊ grid၊ piano roll၊ mixer၊ visual တွေ)၊ "live" mode နဲ့ ပင်လယ်ပေါ်က ဖောက်ထွင်းမြင်ရတဲ့ နောက်ခံ။
- **ဘရောက်ဇာတစ်ခုရဲ့ အခြေခံတွေ:** မှတ်တမ်း၊ bookmark၊ စာမျက်နှာထဲ ရှာဖွေခြင်း၊ zoom၊ right-click၊ download၊ print၊ ပြန်ဖွင့်လို့ရတဲ့ tab တွေနဲ့ နောက်သို့နဲ့ ရှေ့သို့ စာရင်း။
- **ပင်မစကရင်နှစ်ခု:** မီးပြတိုက်နဲ့ ကျွန်းပါတဲ့ သမုဒ္ဒရာ၊ လဲလို့ရတဲ့ icon တွေ၊ ပြောင်းလဲတဲ့ ကောင်းကင်နဲ့ သင့်မြို့ရဲ့ရာသီဥတု (ရွေးချယ်ခွင့်)။
- **အသိုင်းအဝိုင်း theme တွေ:** [`docs/TEMAS.md`](../TEMAS.md) ကို ကြည့်ပါ။ **Mod တွေ:** [`docs/MODS.md`](../MODS.md)။ **လုံခြုံရေး:** [`docs/SEGURANCA.md`](../SEGURANCA.md)။
- **စစ်ဆေးနိုင်တဲ့ ကိုယ်ရေးကိုယ်တာလုံခြုံမှု:** `oceano://rede` က ဘရောက်ဇာကိုယ်တိုင်ရဲ့ ချိတ်ဆက်မှုတိုင်းကို ပြတယ်။

## ကြောင်

<p><img src="../imagens/gato.gif" width="240" alt="ကွန်ပျူတာကို ကိုင်တွယ်နေတဲ့ Oceano ကြောင်"></p>

စိတ်ကြိုက်ရင် သင့် avatar က ကြောင်ဖြစ်နိုင်တယ်။ ကိုယ်ပိုင်ကိုလည်း ပစ်ဇယ်၊ mesh ဒါမှမဟုတ် 3D နဲ့ ဖန်တီးနိုင်တယ်။

## မျက်နှာပြင်ကို လုံခြုံစွာ ရိုက်ကူးခြင်း

Oceano ကို ဗီဒီယိုတွေနဲ့ live တွေမှာ ပေါ်ဖို့ စဉ်းစားထားတာပါ။ ဒေသတွင်း အချက်အလက်တွေ (သင်ဖွင့်ခဲ့တဲ့ ဝဘ်ဆိုက်တွေ၊ လိပ်စာတွေ၊
proxy စည်းမျဉ်းတွေ) ကို သော့ခလောက်ပါတဲ့ ပစ်ဇယ်ဘလောက်တစ်ခုနောက်မှာ ဖုံးထားပြီး ပြတယ်။ နှိပ်လိုက်ရင် အဲဒါက
သင့်လုံခြုံရေးဒေတာရဲ့ အစိတ်အပိုင်းဖြစ်ကြောင်း Oceano က သတိပေးပြီး သင်အတည်ပြုမှသာ ပြပါတယ်။ ဘရောက်ဇာကို ပိတ်လိုက်တဲ့အခါ အားလုံး
ပြန်ဖုံးသွားတယ်။ avatar editor လို ဒေသတွင်း server လိုအပ်တဲ့ အစိတ်အပိုင်းတွေကို Oceano ကိုယ်တိုင်
ဖွင့်ပိတ်ပေးပြီး သင့်ကွန်ပျူတာနဲ့ပဲ ဆက်သွယ်ပါတယ်။

## အသုံးပြုရလွယ်ကူမှု

အသုံးပြုရလွယ်ကူမှုက စတိုင်ထက် ဦးစားပေးတယ်။ theme တိုင်းကို ဖတ်ရလွယ်ရမယ်၊ စာသားအတွက် အနည်းဆုံး contrast 4.5:1
(WCAG AA)၊ အရောင်တစ်ခုတည်းပေါ် မမှီခိုတဲ့ အခြေအနေတွေနဲ့ မြင်ရတဲ့ focus ကွပ်ကာ။ theme editor က contrast ကို
တိုက်ရိုက်စစ်ပြီး မသိမ်းခင် သတိပေးတယ်။ theme တွေ ဖန်တီးတယ်ဆိုရင်
[အသုံးပြုရလွယ်ကူမှု လမ်းညွှန်](../ACESSIBILIDADE-TEMAS.md) ကို ဖတ်ပါ။

- shinshin86 ရဲ့ **[Mesh Avatar Studio](https://github.com/shinshin86/mesh-avatar-studio)** (MIT): လမ်းညွှန်မရဲ့ လှုပ်ရှားနေတဲ့ avatar နဲ့ avatar editor။

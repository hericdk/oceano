# Oceano

ミニマルでオープンな、ピクセルアートのブラウザです。遊ぶ人、作る人、プログラムを書く人のためのものです。
Chromiumをベースに、許可したときだけ匿名で利用数を数え、テーマとLua（PUC-Rioで生まれた言語）のモッドに対応し、
ピクセル化された海の上にウィンドウが並ぶ机、というホームページを備え、制作ツールも
ブラウザの中にそのまま入っています。

> **状態:** 開発中。 → macOS (Apple Silicon) · Windows · Linux: [Releases](https://github.com/hericdk/oceano/releases/latest)

## なぜ存在するのか

> Oceanoは、ただのもうひとつのブラウザになりたいわけではありません。人が作り、学び、夢見ていることを見せられる場所になりたいのです。

Oceanoはピクセルでできていて、本物の海ではありません。でも、海を眺めたときと同じ感覚を届けたいと思っています。
果てしなさ、自由、可能性に満ちた水平線。どこへ行けるだろう？どこまで成長できるだろう？
どこにたどり着けるだろう？ それに答える手助けをするために存在していて、だから無料なのです。

何かを作る人、動画を撮る人のために作られていて、とくに始めたばかりの人に向けています。自分の
ビジネス、アイデア、夢を紹介したり、Vlogを作ったり。どのツールも何かを教えてくれるべきで、コミュニティ
（知識を交換するグループで、フォーラムのようなリズム）が、ひとりひとりの成長を助けるべきだと考えています。これが
プロジェクト全体を導く前提です。[マニフェスト](../MANIFESTO.md)を読んでみてください。

ブラウザはどれも似てきて、誰も頼んでいないものであふれています。Oceanoはその
逆を目指します。小さくて、美しくて、検証できて、いじって遊べるもの。守るより、集めないほうがいい。
すべてはあなたのコンピュータに残り、アカウントは必須ではありません。

これは中期から長期のプロジェクトです。何年にもわたって取り組むつもりで、
Sean MurrayがNo Man's Skyに打ち込んだように、早めにリリースして、使ってくれる人の声を聞き、バージョンを
重ねて改良を続け、約束しているブラウザになるまで育てていきます。しかも、オープンにやります。ほかの
人たちが学び、刺激を受け、アイデアを先へ運んでいけるように。

ビジョンの全体は[`docs/VISAO.md`](../VISAO.md)にあります。

### 作った本人が答える4つの質問

**使う人に何かを教えてくれる？**

ぼく（わたし）は、音楽を学ぶのは難しいと思っていました。シンセサイザーに触れて、そうじゃないとわかりました。だれにでも同じように使えるようにして、ほかの人も学べるようにしたいのです。

**初心者にも使えて、動画で見栄えがする？**

はい！ ここでできることを見せる動画を作る人が増えれば増えるほど、ほかにはない自由なものを作り始める人も増えていきます。

**プライバシーとアクセシビリティを大切にしている？**

最初からの基本原則です。どちらも大切で必要なものなので、このベータの最初のテストでは、みなさんの協力をあてにしています。

**人と人を近づける？**

将来はどうでしょう？ Redditのようなディスカッションフォーラムができたら、とても良いと思います。それに、とても軽い3D雰囲気づくりのグラフィックツールがすでにあります。空、灯台、雨のある海のシーン全体が、29 KBのコードに収まっています。人と人を近づけるための大きな可能性が開けます 👀

> わたしたちには、新しくて、安全で、つながっていて、自由で、使う人を助けるために考えられたものを作る、すばらしい可能性があります。感謝、共感、交流のしるしとして。そして、これをずっと広告なしで保つつもりです。

## すでにあるもの

| フォルダ | 内容 | 実行方法 |
|---|---|---|
| [`simulador/`](../../simulador/) | インターフェース全体をひとつのページで動かします。タブ、机、テーマ、Lua/Tealのモッド、サウンドトラック、Strudel、PICO-8、水分補給のリマインダー | `python3 simulador/serve.py 5216` を実行して http://localhost:5216 を開く |
| [`app/`](../../app/) | Electron製のMVP。同じインターフェースに、本物のタブ（Chromium）、分離されたプロファイル、ブロッカー、ミニプレーヤーがつきます | `cd app && npm install && npm start` |
| [`extensao/`](../../extensao/) | Oceano Lite：Oceanoの新しいタブをChrome拡張機能にしたもの | `extensao/README.md` を参照 |
| [`docs/`](../) | ビジョンと計画 | — |

今日できることの例です。

- **机としてのホームページ:** 灯台のある海の上で、ウィンドウをドラッグ、折りたたみ、閉じることができます。プロファイルごとに自分の机があります。
- **テーマ**（`oceano-tema/1`、JSONのみ）で、色、ピクセル化、さらには海の時間帯まで変えられます。
- **Lua 5.4 / Tealのモッド**を、権限を宣言したサンドボックスの中で動かします。
- **タブグループ**をホームページに保存し、メモリを使わないよう閉じておきます。
- **AI検索**（任意、自分のキーを使用）は、一行で答えて、適切なサイトを案内します。
- **音楽:** ジェネレーティブなサウンドトラックと、[Stave](https://stave.live)を通したStrudelでのライブコーディング（タイムライン、グリッド、ピアノロール、ミキサー、ビジュアル）。「ライブ」モードと、海の上の透明な背景にも対応しています。
- **ブラウザの基本:** 履歴、ブックマーク、ページ内検索、ズーム、右クリック、ダウンロード、印刷、戻ってくるタブ、「戻る」と「進む」の一覧。
- **2つのホーム画面:** 灯台のある海と島。アイコンで切り替えられ、空は移り変わり、あなたの街の天気も表示できます（任意）。
- **コミュニティのテーマ:** [`docs/TEMAS.md`](../TEMAS.md)を参照。**モッド:** [`docs/MODS.md`](../MODS.md)。**セキュリティ:** [`docs/SEGURANCA.md`](../SEGURANCA.md)。
- **検証できるプライバシー:** `oceano://rede` が、ブラウザ自身のすべての接続を表示します。

## 安全に画面を録画する

Oceanoは、動画やライブ配信に映ることを考えて作られています。ローカルの情報（開いたサイト、アドレス、
プロキシのルール）は、鍵のついたピクセルのブロックの後ろに隠れて表示されます。クリックすると、Oceanoは
それがセキュリティに関わるデータだと知らせ、確認したときだけ表示します。ブラウザを閉じると、すべてが
また隠れた状態に戻ります。アバターエディタのようにローカルサーバーが必要な部分は、
Oceano自身がオンとオフを切り替え、あなたのコンピュータとだけやり取りします。

## アクセシビリティ

アクセシビリティはスタイルよりも先に来ます。どのテーマも読みやすくあるべきです。テキストのコントラストは最低4.5:1
（WCAG AA）、色だけに頼らない状態表示、見えるフォーカスの輪郭。テーマエディタはコントラストを
リアルタイムで確認し、保存する前に知らせてくれます。テーマを作る人は、
[アクセシビリティガイド](../ACESSIBILIDADE-TEMAS.md)を読んでください。

## クレジット

Oceanoは、たくさんの人の仕事の上に作られています。とくに次のものです。

- **[Stave](https://stave.live)**、Mrityunjay Bhardwaj作（[GitHubのコード](https://github.com/MrityunjayBhardwaj/Stave)、AGPL-3.0）：Oceanoの中の音楽スタジオ（`oceano://stave`）。タイムライン、グリッド、ピアノロール、ミキサー、ビジュアルを備えています。Oceanoでは、「ライブ」モード、透明な背景、音楽つきの動画録画が加わりました。
- **[Strudel](https://strudel.cc)**、Felix Roos、Alex McLean、コミュニティ作（[コード](https://codeberg.org/uzu/strudel)、AGPL-3.0）：Staveを動かす、コードで音楽を作る言語。
- **[Mesh Avatar Studio](https://github.com/shinshin86/mesh-avatar-studio)**、shinshin86作（MIT）：ナビゲーターのアニメーションするアバターと、アバターエディタ。
- **Lua**（PUC-Rio）、**Teal**（Hisham Muhammad）、**three.js**、**Chromium**、**Electron**。
- **四足歩行ロボットの3Dモデル**（`simulador/robo/modelos/quadrupede.3mf`）。ファイル自体のデータによるとBY-NCライセンスです。**四足歩行ロボットでのみ**使われ、ほかのロボットでは使われません。OceanoのGPLのもとにはなく、商用利用はできません。

- **[Whisper](https://github.com/openai/whisper)**、OpenAI作（MIT）。[onnx-community](https://huggingface.co/onnx-community/whisper-base)によるONNX変換版（Apache-2.0）：音声の文字起こしで、コンピュータ上で動き、ユーザーが求めたときだけダウンロードされます。
- **[Open-Meteo](https://open-meteo.com)**：天気と都市の検索。キーもアカウントも不要です。

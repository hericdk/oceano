# Oceano

ບຣາວເຊີນ້ອຍໆ ເປີດກວ້າງ ແລະເປັນ pixel art ສຳລັບຄົນທີ່ຫຼິ້ນເກມ, ສ້າງສັນ ແລະຂຽນໂປຣແກຣມ.
ອີງໃສ່ Chromium, ນັບການນຳໃຊ້ແບບບໍ່ລະບຸຕົວຕົນສະເພາະເມື່ອເຈົ້າອະນຸຍາດ, ມີທີມ (theme) ແລະ mod ດ້ວຍພາສາ Lua (ພາສາທີ່ສ້າງຂຶ້ນທີ່ PUC-Rio),
ໜ້າຫຼັກທີ່ເປັນໂຕະຂອງໜ້າຕ່າງເທິງທະເລ pixel, ແລະເຄື່ອງມືສ້າງສັນ
ຢູ່ໃນບຣາວເຊີເອງ.

## ເປັນຫຍັງຈຶ່ງມີ

> Oceano ບໍ່ຢາກເປັນພຽງບຣາວເຊີອີກອັນໜຶ່ງ. ມັນຢາກເປັນບ່ອນທີ່ຜູ້ຄົນສ້າງ, ຮຽນຮູ້ ແລະສະແດງສິ່ງທີ່ເຂົາເຈົ້າຝັນ.

Oceano ເຮັດຈາກ pixel, ບໍ່ແມ່ນທະເລຈິງ, ແຕ່ຢາກໃຫ້ຄວາມຮູ້ສຶກດຽວກັນກັບການເບິ່ງທະເລ:
ຄວາມກວ້າງໃຫຍ່, ເສລີພາບ, ຂອບຟ້າທີ່ເຕັມໄປດ້ວຍຄວາມເປັນໄປໄດ້. ຂ້ອຍໄປໃສໄດ້ແດ່? ຂ້ອຍເຕີບໂຕໄດ້ເຖິງໃສ?
ຂ້ອຍໄປເຖິງໃສໄດ້? ມັນມີຢູ່ເພື່ອຊ່ວຍໃຫ້ຜູ້ຄົນຕອບຄຳຖາມນີ້, ແລະດ້ວຍເຫດນັ້ນຈຶ່ງບໍ່ເສຍເງິນ.

ມັນຖືກສ້າງສຳລັບຜູ້ສ້າງສັນ ແລະຄົນທີ່ຖ່າຍວິດີໂອ, ໂດຍສະເພາະຄົນທີ່ກຳລັງເລີ່ມຕົ້ນ: ນຳສະເໜີທຸລະກິດ
ຂອງຕົນເອງ, ແນວຄິດ, ຄວາມຝັນ, ເຮັດ vlog. ທຸກເຄື່ອງມືຕ້ອງສອນຫຍັງບາງຢ່າງ, ແລະຊຸມຊົນ
(ກຸ່ມແລກປ່ຽນຄວາມຮູ້, ຈັງຫວະແບບເວທີສົນທະນາ) ຕ້ອງຊ່ວຍໃຫ້ແຕ່ລະຄົນເຕີບໂຕ. ນັ້ນຄືຫຼັກການ
ທີ່ນຳທາງທັງໂຄງການ: ອ່ານ[ແຖລງການ](../MANIFESTO.md).

ບຣາວເຊີຕ່າງໆກາຍເປັນຄືກັນໝົດ ແລະເຕັມໄປດ້ວຍສິ່ງທີ່ບໍ່ມີໃຜຂໍ. Oceano ຢາກໄດ້
ກົງກັນຂ້າມ: ນ້ອຍ, ງາມ, ກວດສອບໄດ້ ແລະສ້າງມາເພື່ອໃຫ້ລອງແກ້ໄຂ. ບໍ່ເກັບຂໍ້ມູນດີກວ່າການປົກປ້ອງ;
ທຸກຢ່າງຢູ່ໃນຄອມພິວເຕີຂອງເຈົ້າ; ບໍ່ບັງຄັບມີບັນຊີ.

ນີ້ເປັນໂຄງການໄລຍະກາງແລະໄລຍະຍາວ. ແນວຄິດຂອງຂ້ອຍແມ່ນອຸທິດຕົນໃຫ້ມັນຫຼາຍປີ, ຄືກັບທີ່
Sean Murray ອຸທິດໃຫ້ No Man's Sky: ປ່ອຍແຕ່ຫົວທີ, ຟັງຄົນທີ່ໃຊ້, ແລະສືບຕໍ່ປັບປຸງ, ເວີຊັນ
ແລ້ວເວີຊັນເລົ່າ, ຈົນກວ່າຈະກາຍເປັນບຣາວເຊີທີ່ມັນສັນຍາໄວ້. ແລະເຮັດແບບເປີດເຜີຍ, ເພື່ອໃຫ້ຄົນອື່ນ
ສາມາດສຶກສາ, ຮັບແຮງບັນດານໃຈ ແລະນຳແນວຄິດໄປຕໍ່.

ວິໄສທັດສົມບູນຢູ່ໃນ [`docs/VISAO.md`](../VISAO.md).

### ສີ່ຄຳຖາມ, ຕອບໂດຍຜູ້ສ້າງ

**ມັນສອນຫຍັງຄົນທີ່ໃຊ້ບໍ?**

ຂ້ອຍເຄີຍຄິດວ່າການຮຽນດົນຕີຍາກ. ດ້ວຍ synthesizer, ຂ້ອຍພົບວ່າບໍ່ແມ່ນ. ຂ້ອຍຢາກໃຫ້ການເຂົ້າເຖິງທີ່ເທົ່າທຽມກັນ ເພື່ອໃຫ້ຄົນອື່ນຮຽນໄດ້ຄືກັນ.

**ໃຊ້ໄດ້ສຳລັບຄົນທີ່ກຳລັງເລີ່ມ ແລະອອກມາງາມໃນວິດີໂອບໍ?**

ໄດ້! ແລະຍິ່ງມີຄົນເຮັດວິດີໂອສະແດງສິ່ງທີ່ເຮັດໄດ້ຢູ່ນີ້ຫຼາຍເທົ່າໃດ, ກໍຍິ່ງມີຄົນເລີ່ມສ້າງສິ່ງທີ່ເປັນເອກະລັກ ແລະເສລີຫຼາຍຂຶ້ນ.

**ເຄົາລົບຄວາມເປັນສ່ວນຕົວ ແລະການເຂົ້າເຖິງໄດ້ງ່າຍບໍ?**

ເປັນຫຼັກການພື້ນຖານຕັ້ງແຕ່ເລີ່ມ. ທັງສອງສິ່ງສຳຄັນແລະຈຳເປັນ, ແລະຂ້ອຍອາໄສການສະໜັບສະໜູນຈາກທຸກຄົນໃນການທົດສອບທຳອິດຂອງເບຕ້ານີ້.

**ເຮັດໃຫ້ຜູ້ຄົນໃກ້ຊິດກັນຫຼາຍຂຶ້ນບໍ?**

ໃນອະນາຄົດ, ບາງທີ? ເວທີສົນທະນາແບບ Reddit ຈະດີຫຼາຍ. ແລະພວກເຮົາມີເຄື່ອງມືກຣາຟິກສຳລັບບັນຍາກາດ 3D ທີ່ເບົາຫຼາຍແລ້ວ: ສາກທະເລທັງໝົດ, ພ້ອມທ້ອງຟ້າ, ປະພາຄານ ແລະຝົນ, ໃສ່ໄດ້ໃນໂຄ້ດ 29 KB. ນີ້ເປີດທ່າແຮງອັນໃຫຍ່ຫຼວງໃນການເຮັດໃຫ້ຜູ້ຄົນໃກ້ຊິດກັນ 👀

> ພວກເຮົາມີທ່າແຮງທີ່ໜ້າອັດສະຈັນໃນການສ້າງສິ່ງໃໝ່, ປອດໄພ, ເຊື່ອມຕໍ່ກັນ, ເສລີ ແລະຄິດມາເພື່ອຊ່ວຍຄົນທີ່ໃຊ້ມັນ, ເປັນສັນຍາລັກຂອງຄວາມກະຕັນຍູ, ຄວາມເຫັນອົກເຫັນໃຈ ແລະການແລກປ່ຽນ. ແລະຂ້ອຍຕັ້ງໃຈຮັກສາທັງໝົດນີ້ໃຫ້ປາສະຈາກໂຄສະນາ.

- **ດົນຕີ:** ດົນຕີພື້ນຫຼັງທີ່ສ້າງອັດຕະໂນມັດ ແລະ live coding ດ້ວຍ Strudel ຜ່ານ [Stave](https://stave.live) (timeline, ຕາຕະລາງ, piano roll, mixer, ພາບ), ມີໂໝດ "ສົດ" ແລະພື້ນຫຼັງໂປ່ງໃສເທິງທະເລ.
- **ພື້ນຖານຂອງບຣາວເຊີ:** ປະຫວັດ, ບຸກມາກ, ຄົ້ນຫາໃນໜ້າ, ຊູມ, ຄລິກຂວາ, ດາວໂຫຼດ, ພິມ, ແຖບທີ່ເປີດຄືນໄດ້ ແລະລາຍຊື່ໃນຍ້ອນກັບ ແລະໄປໜ້າ.
- **ໜ້າຈໍຫຼັກສອງແບບ:** ມະຫາສະໝຸດທີ່ມີປະພາຄານ ແລະເກາະ, ມີໄອຄອນໃຫ້ປ່ຽນ, ທ້ອງຟ້າທີ່ປ່ຽນໄປ ແລະອາກາດຂອງເມືອງເຈົ້າ (ທາງເລືອກ).

- **ຄວາມເປັນສ່ວນຕົວທີ່ກວດສອບໄດ້:** `oceano://rede` ສະແດງທຸກການເຊື່ອມຕໍ່ຂອງບຣາວເຊີເອງ.

## ບັນທຶກໜ້າຈໍຢ່າງປອດໄພ

Oceano ຖືກຄິດມາເພື່ອປາກົດໃນວິດີໂອ ແລະການຖ່າຍທອດສົດ. ຂໍ້ມູນໃນເຄື່ອງ (ເວັບໄຊທີ່ເຈົ້າເປີດ, ທີ່ຢູ່,
ກົດຂອງ proxy) ປາກົດແບບຖືກເຊື່ອງໄວ້ຫຼັງບລັອກ pixel ທີ່ມີກະແຈ. ເມື່ອຄລິກ, Oceano ແຈ້ງວ່າ
ສິ່ງນັ້ນເປັນສ່ວນໜຶ່ງຂອງຂໍ້ມູນຄວາມປອດໄພຂອງເຈົ້າ ແລະສະແດງສະເພາະເມື່ອເຈົ້າຢືນຢັນ; ເມື່ອປິດບຣາວເຊີ, ທຸກຢ່າງກັບຄືນໄປ
ຖືກເຊື່ອງໄວ້. ສ່ວນທີ່ຕ້ອງໃຊ້ເຊີເວີໃນເຄື່ອງ, ເຊັ່ນຕົວແກ້ໄຂ avatar, Oceano ເປັນຜູ້ເປີດ ແລະ
ປິດເອງ ແລະຄຸຍກັບຄອມພິວເຕີຂອງເຈົ້າເທົ່ານັ້ນ.

## ການເຂົ້າເຖິງໄດ້ງ່າຍ

ການເຂົ້າເຖິງໄດ້ງ່າຍມາກ່ອນສະໄຕລ໌. ທຸກທີມຕ້ອງອ່ານງ່າຍ: ຄວາມຕັດກັນຂອງສີຢ່າງຕ່ຳ 4.5:1 ສຳລັບຂໍ້ຄວາມ
(WCAG AA), ສະຖານະທີ່ບໍ່ອາໄສສີຢ່າງດຽວ ແລະເສັ້ນຂອບໂຟກັດທີ່ເຫັນໄດ້. ຕົວແກ້ໄຂທີມກວດ
ຄວາມຕັດກັນຂອງສີແບບສົດ ແລະເຕືອນກ່ອນບັນທຶກ. ຖ້າເຈົ້າສ້າງທີມ, ອ່ານ
[ຄູ່ມືການເຂົ້າເຖິງໄດ້ງ່າຍ](../ACESSIBILIDADE-TEMAS.md).

- **[Strudel](https://strudel.cc)** ຂອງ Felix Roos, Alex McLean ແລະຊຸມຊົນ ([ໂຄ້ດ](https://codeberg.org/uzu/strudel), AGPL-3.0): ພາສາດົນຕີດ້ວຍໂຄ້ດທີ່ຂັບເຄື່ອນ Stave.
- **[Mesh Avatar Studio](https://github.com/shinshin86/mesh-avatar-studio)** ຂອງ shinshin86 (MIT): avatar ເຄື່ອນໄຫວຂອງຜູ້ນຳທາງ ແລະຕົວແກ້ໄຂ avatar.

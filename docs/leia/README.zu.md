# Oceano

Isiphequluli esincane, esivulekile nesenziwe nge-pixel art, kwabadlala, abadala nabaqamba izinhlelo.
Sakhelwe phezu kwe-Chromium, sinokubalwa kokusetshenziswa okungadaluli igama kuphela uma uvuma, sinezindikimba nama-mod e-Lua (ulimi olwakhiwe yi-PUC-Rio),
ikhasi lokuqala eliyithebula lamawindi phezu kwolwandle lwe-pixel, namathuluzi okudala
ngaphakathi esiphequluli ngokwaso.

> **Isimo:** siyathuthukiswa. → macOS (Apple Silicon) · Windows · Linux: [Releases](https://github.com/hericdk/oceano/releases/latest)

## Kungani sikhona

> I-Oceano ayifuni ukuba esinye nje isiphequluli. Ifuna ukuba yindawo lapho abantu badala khona, bafunda futhi babonise abakuphusheleyo.

I-Oceano yenziwe ngama-pixel, asilona ulwandle lwangempela, kodwa ifuna ukunikeza umuzwa ofanayo wokulubheka:
ubukhulu balo, inkululeko, umphetho wesibhakabhaka ogcwele amathuba. Ngingaya kuphi? Ngingakhula kuze kube kuphi?
Ngingafika kuphi? Ikhona ukusiza abantu ukuba baphendule lokhu, yingakho ingenamali.

Yenzelwe abadali nabarekhoda amavidiyo, ikakhulukazi abaqalayo: ukwethula
ibhizinisi labo, umqondo, iphupho, ukwenza i-vlog. Ithuluzi ngalinye kufanele lifundise okuthile, futhi umphakathi
(amaqembu okushintshana ngolwazi, ngesigqi se-forum) kufanele usize umuntu ngamunye akhule. Lesi yisisekelo
esiqondisa lonke iphrojekthi: funda [isimemezelo](../MANIFESTO.md).

Iziphequluli sezafana futhi zigcwele izinto ongekho owazicelayo. I-Oceano ifuna
okuphambene nalokho: incane, ihle, iyaqinisekiseka futhi yenzelwe ukuthi uyidlale. Ukungaqoqi kungcono kunokuvikela;
yonke into ihlala kukhompyutha yakho; akukho i-akhawunti okuphoqelelwe.

Leli yiphrojekthi lesikhathi esiphakathi nesinde. Umqondo wukuzinikela kulo iminyaka eminingi, njengoba
uSean Murray azinikela ku-No Man's Sky: ukukhipha kusenesikhathi, ukulalela abayisebenzisayo nokuqhubeka nokuthuthukisa, inguqulo
ngemuva kwenguqulo, kuze kube yisiphequluli esithembisa ukuba yiso. Futhi ukwenza lokho ngokuvulekile, ukuze abanye abantu
bakwazi ukufunda, bathole umphefumulo bese beqhubekisela phambili imibono.

Umbono ophelele ukwi-[`docs/VISAO.md`](../VISAO.md).

### Imibuzo emine, iphendulwe ngowayidalayo

**Ingabe lokhu kufundisa okuthile lowo oyisebenzisayo?**

Ngangicabanga ukuthi ukufunda umculo kunzima. Nge-synthesizer, ngathola ukuthi akunjalo. Ngifuna ukunikeza ithuba elilinganayo ukuze nabanye abantu bakwazi ukufunda.

**Isebenzela abaqalayo futhi ibukeka kahle evidiyweni?**

Yebo! Futhi uma abantu abaningi benza amavidiyo abonisa okungenziwa lapha, abantu abaningi bazoqala ukudala into eyingqayizivele nekhululekile.

**Iyakhuluma ukubaluleka kwemfihlo nokufinyeleleka?**

Kuyisimiso esiyisisekelo kusukela ekuqaleni. Zombili ziyabaluleka futhi ziyadingeka, futhi ngithembele ekwesekweni kwabo bonke ekuhlolweni kokuqala kwale beta.

**Iyabasondeza abantu komunye nomunye?**

Esikhathini esizayo, ubani ukwazi? I-forum yezingxoxo yesitayela se-Reddit ingaba nomthelela omuhle kakhulu. Futhi sesivele sinethuluzi lemifanekiso yendawo ye-3D elinesisindo esincane kakhulu: lonke indawo yolwandle, nesibhakabhaka, ihlobo lokukhanyisa nemvula, ilingana ku-29 KB wekhodi. Lokhu kuvula amandla amakhulu okusondeza abantu 👀

> Sinamandla angakholeki okudala into entsha, ephephile, exhumene, ekhululekile futhi eyakhelwe ukusiza abazoyisebenzisa, njengophawu lokubonga, uzwela nokushintshana. Futhi ngihlela ukugcina konke lokhu kungenazo izikhangiso.

Ezinye izinto ongazenza namuhla:

- **Ikhasi lokuqala njengethebula:** amawindi owadonsayo, owagoqayo futhi uwavale phezu kolwandle olunesibani esikhanyayo; iphrofayili ngayinye inethebula layo.
- **Izindikimba** (`oceano-tema/1`, i-JSON kuphela) eziguqula imibala, ukubukeka kwe-pixel nehora losuku lolwandle.
- **Ama-mod e-Lua 5.4 / Teal** ku-sandbox enezimvume ezimenyezelwe.
- **Amaqembu amathebhu** agcinwe ekhasini lokuqala, avaliwe ukuze angadli inkumbulo.
- **Usesho nge-AI** (ngokuzikhethela, ngokhiye wakho) oluphendula ngomugqa owodwa futhi lukhombise amasayithi alungile.
- **Umculo:** umculo ongemuva ozizalelayo ne-live coding nge-Strudel ngokusebenzisa i-[Stave](https://stave.live) (timeline, igridi, piano roll, mixer, okubonwayo), unemodi ye-"bukhoma" nangemuva okuhloniphekile phezu kolwandle.
- **Okuyisisekelo sesiphequluli:** umlando, amabhukhimakhi, ukucinga ekhasini, ukukhulisa, ukuchofoza kwesokudla, ukulanda, ukuphrinta, amathebhu abuyayo nohlu lokubuyela emuva nokuya phambili.
- **Izikrini ezimbili zokuqala:** ulwandle olunesibani nesiqhingi, ngezithonjana zokushintsha, isibhakabhaka esiguquguqukayo nesimo sezulu sedolobha lakho (ngokuzikhethela).
- **Izindikimba zomphakathi:** bheka [`docs/TEMAS.md`](../TEMAS.md). **Ama-mod:** [`docs/MODS.md`](../MODS.md). **Ukuphepha:** [`docs/SEGURANCA.md`](../SEGURANCA.md).
- **Imfihlo eqinisekiswayo:** `oceano://rede` ibonisa konke ukuxhumana kwesiphequluli ngokwaso.

## Ukurekhoda isikrini ngokuphepha

I-Oceano yakhelwe ukuvela emavidiyo nasemisakazweni ebukhoma. Ulwazi lwasendaweni (amasayithi owavulile, amakheli,
imithetho ye-proxy) livela lifihlwe ngemuva kwebhlokhi ye-pixel enokhiye. Uma uchofoza, i-Oceano ikwazisa ukuthi
lokho kuyingxenye yedatha yakho yokuphepha futhi iyayibonisa kuphela uma uqinisekisa; uma uvala isiphequluli, konke kubuyela
ekufihlweni. Izingxenye ezidinga iseva yasendaweni, njengomhleli we-avatar, zivulwa futhi
zivalwa yi-Oceano ngokwayo futhi zikhuluma kuphela nekhompyutha yakho.

## Ukufinyeleleka

Ukufinyeleleka kuza ngaphambi kwesitayela. Isindikimba ngasinye kufanele sifundeke kalula: umehluko omncane ongu-4,5:1 wombhalo
(WCAG AA), izimo ezingathembeli emibalweni kuphela nomugqa wokugxila obonakalayo. Umhleli wezindikimba ubheka
umehluko ngokuphila futhi ukuxwayise ngaphambi kokugcina. Uma udala izindikimba, funda
[umhlahlandlela wokufinyeleleka](../ACESSIBILIDADE-TEMAS.md).

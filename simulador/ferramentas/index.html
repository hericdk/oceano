Como ativar

O Baixar e o Editor de vídeo funcionam no app do Oceano, com o yt-dlp e o ffmpeg instalados neste computador. Nada passa por fora dele.

Mac: cole no app Terminal (Aplicativos → Utilitários) e aperte Enter.

brew install yt-dlp ffmpeg

Se o Mac não reconhecer o brew, instale antes o Homebrew, o instalador de programas pelo Terminal. Ele é grátis, vem de brew.sh e pode pedir a senha do Mac no próprio Terminal:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Windows: cole no Terminal ou no PowerShell (procure no menu Iniciar) e aperte Enter.

winget install yt-dlp.yt-dlp Gyan.FFmpeg

O winget já vem no Windows 10 e 11. Se não aparecer, atualize o Instalador de Aplicativo pela Microsoft Store.

Linux: cole no Terminal (Ctrl+Alt+T na maioria dos sistemas) e aperte Enter.

sudo apt install yt-dlp ffmpeg

O apt já vem no Ubuntu e no Debian. Em outros sistemas, use o instalador de pacotes que vier com eles.

Os sites mudam com frequência: se um link parar de funcionar, atualize o yt-dlp.
